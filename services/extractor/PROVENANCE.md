# Provenance

`extract.py`, `acord25.py`, `server.py`, `requirements.txt` and `Dockerfile` were
adapted on 2026-11-10 from an earlier personal project of the repository owner.
The owner confirmed in the project session that the code is their own work,
written outside working hours, and authorized its reuse here.

Changes on import: product references renamed, one template-specific module and
its endpoint left out, an example company name in a comment replaced with a
fictional one. No test fixtures, sample documents or data were imported.

Third-party libraries (docTR, pdfplumber, pypdfium2, PyTorch) keep their own
licenses; see `requirements.txt`.

Status: imported but not yet run or tested in this repository.
